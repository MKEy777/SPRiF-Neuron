\begin{abstract}
Spiking neural networks must retain information across delays while continuing to communicate through spikes. In standard leaky integrate-and-fire neurons, input integration and spike reset share the same membrane state, allowing each discharge to disturb the trace of past input. To address this coupling, we propose SPRiF, a five-state spiking neuron that separates spectral memory from the firing membrane. A real decay mode and a damped rotational pair provide persistent and phase-dependent representations of input history. Immediate and delayed readouts combine these representations to shape the membrane drive, while scalar membrane reset preserves the memory coordinates at discharge. Analysis of the temporal kernel characterizes this separation and identifies the additional spike-history term introduced when reset acts on spectral memory. Experiments on S-MNIST, PS-MNIST, QTDB, GSC and SHD show that SPRiF exceeds the compared published accuracies on four of the five benchmarks. Across three datasets, SPRiF consistently outperforms capacity-matched controls that reset spectral memory or use an all-real memory basis. Delayed matching experiments further demonstrate robust memory retention under forced spikes and an unseen delay. These results demonstrate the value of combining structured temporal dynamics with memory-preserving reset for temporal classification and delayed decisions under intervening spike activity.
\end{abstract}

\section{Introduction}
\label{sec:introduction}

\IEEEPARstart{T}{emporal} classification requires a model to combine evidence that arrives at different times. In a delayed decision, an early cue may no longer be present when a later cue determines its interpretation. A spiking neural network, or SNN, must preserve that earlier evidence while communicating through spikes. Its neurons must therefore retain useful temporal traces without allowing discharge to rewrite the evidence needed for later decisions.

In the leaky integrate-and-fire model, abbreviated LIF, input integration, spike generation and reset act on the same membrane state. An input pulse and a subsequent spike-induced reset therefore leave traces governed by the same decay. Increasing the membrane time constant prolongs both traces without separating retained input from the effect of firing. A single exponential mode also gives an isolated pulse a fixed-sign response. Effective temporal processing thus requires both an expressive temporal basis and a reset rule that preserves it at discharge.

Existing neuron models address these requirements through several mechanisms. Adaptation retains activity in thresholds or currents~\cite{asrnn,adlif,radlif}, while heterogeneous neurons and synapses distribute integration across time scales~\cite{heterogeneity,hetsyn}. Resonant dynamics add phase-dependent responses~\cite{izhikevich_rf,brf,drf}, and compartmental models distribute integration across interacting states~\cite{tclif,dhsnn}. Memory organization and reset design offer further choices. PMSN separates linear hidden compartments from a firing compartment~\cite{pmsn2026}, DMP-SNN shares memory across a layer~\cite{sun2026dmp}, and reset rules may be softened, adapted or removed~\cite{inflor,arlif,psn}. These studies motivate a common local-capacity comparison of the temporal basis used to retain input and the state pathway modified by firing.

We study temporal modes and reset placement jointly under a fixed local state budget. The temporal basis determines which histories are available to the membrane, while reset placement determines whether discharge changes them. Matching local capacity allows us to compare state organization without adding storage or learned coefficients.

We introduce SPRiF, a five-state neuron comprising a three-coordinate spectral memory, an auxiliary filter and a firing membrane. The spectral block combines a real decay with a damped rotation to provide persistence and phase-dependent weighting of past input. Two learned projections connect this memory to the membrane. One acts immediately; the other passes through the auxiliary filter and arrives one step later. The delayed route changes the response to older input without changing the response at pulse onset. A spike resets only the membrane, leaving the spectral and auxiliary coordinates continuous at discharge. Spikes can still affect future inputs through recurrent feedback.

We connect this local construction to network behavior through analysis and experiments. The input-to-drive kernel isolates the spike-history term introduced by resetting spectral memory. Five temporal benchmarks test transfer across input representations, while matched controls vary reset placement and temporal modes at fixed local capacity. The Spike-Intervention Delayed Match-to-Sample task, abbreviated SI-DMS, tests whether a learned delayed decision remains stable under forced intervening activity.

The work makes three contributions.
\begin{enumerate}
\item We propose a five-state spiking neuron that combines a real decay and a damped rotation with immediate and delayed membrane readouts. Scalar membrane reset preserves the local spectral memory at discharge while retaining binary spike generation.
\item We derive the temporal kernel and separate the direct effect of memory reset from recurrent spike feedback. The analysis also establishes controllability of the spectral state and boundedness of the local states under the stated parameter and input conditions.
\item We evaluate SPRiF across five temporal benchmarks and assess its two design choices with capacity-matched controls. Preserving memory at reset adds 3.37, 4.56 and 2.03 percentage points on PS-MNIST, SHD and QTDB. Retaining the rotational pair adds 2.34, 2.47 and 5.04 points, respectively (Table~\ref{tab:ablation}). In SI-DMS, five-seed mean accuracy at 40 forced-spike timesteps reaches 99.42\% after clean training and 99.33\% after intervention training, averaged over five delays (Table~\ref{tab:sidms_results}).
\end{enumerate}

\section{Related Work}
\label{sec:related}

\subsection{Temporal Dynamics in Spiking Neurons}

Adaptive neurons extend temporal processing through variables that influence later firing. ASRNN combines adaptive spiking dynamics with recurrent processing for time-domain classification~\cite{asrnn}, while the adLIF family, including the SE-adLIF comparator in Table~\ref{tab:main_results}, uses adaptation for spatiotemporal processing~\cite{adlif}. SNN-SFA retains information through a slowly varying firing threshold~\cite{snnsfa}, whereas RadLIF combines recurrent connections with an adaptive current driven by subthreshold voltage and spike-triggered increments~\cite{radlif}. These models carry activity beyond the membrane time constant by changing either the threshold for future firing or the current that opposes membrane integration.

Temporal diversity can also be distributed across parameters, neurons or synapses. DA-LIF learns independent decays for spatial and temporal tuning~\cite{dalif}. Heterogeneous SNN and bimodal time-scale networks combine neurons with different integration rates~\cite{heterogeneity,bimodal}, while HetSyn places time constants in synaptic currents~\cite{hetsyn}. Conductance-based models obtain multiple scales through fast, slow and ultra-slow conductances~\cite{mtc}. These approaches broaden the range of memory durations. SPRiF also shapes the retained response. A real decay gives an isolated pulse a fixed-sign trace, whereas a rotational pair exposes its changing phase to the readout. Their combination provides persistence and phase-dependent weighting within one neuron.

Resonate-and-fire neurons use coupled states whose phase affects the response to past input~\cite{izhikevich_rf}. BRF develops balanced resonate-and-fire dynamics for trainable spiking networks~\cite{brf}, and PRF combines resonant membrane dynamics with a decoupled reset construction for parallel sequence processing~\cite{prf}. SPRiF uses the resonant pair as an explicit memory basis and reads it through a separate firing membrane.

Compartmental models distribute dynamics across dendritic and somatic states. Dendrify provides reduced models with dendritic integration and local spikes~\cite{dendrify}, TC-LIF couples dendritic and somatic states~\cite{tclif}, and DH-SNN assigns heterogeneous time constants to dendritic branches~\cite{dhsnn}. D-RF is closely related to SPRiF. Its resonant dendrites feed a somatic readout, its threshold depends on spike history, and its dendrites evolve without subtractive output reset~\cite{drf}. SPRiF gives the firing membrane two learned projections of the spectral state. The second passes through an auxiliary filter and arrives one step later, changing the delayed response without changing the response at pulse onset. The temporal kernel below describes this separation.

State-space models motivate both the parameterization of spiking dynamics and their organization within a sequence model. SiLIF transfers learnable discretization and logarithmic parameterization to spiking neurons, including a complex-state variant with oscillatory regimes~\cite{silif}. SpikingSSMs combine state-space sequence processing with sparse spiking outputs~\cite{spikingssms}. SPRiF specifies one real pole and one complex-conjugate pair directly, then learns how these states reach the membrane through immediate and delayed projections.

\subsection{Reset Mechanisms and Spike History}

PMSN separates the dynamics of hidden compartments from discharge at its output~\cite{pmsn2026}. Unrolling its diagonalized hidden transition gives a convolution from injected current to the output-compartment drive. Its parallel output update uses a temporal-decoupled reset that operates on rectified current and discharges integer multiples of the threshold. SPRiF instead uses a leaky membrane with signed drive and one threshold subtraction per binary spike. This choice preserves a sequential firing decision while keeping the drive kernel analytically tractable.

Reset design determines the state available after firing. Guo \emph{et al.} use a soft reset and membrane-potential rectification to reduce information loss~\cite{inflor}; AR-LIF adapts reset through the relation between input and output~\cite{arlif}; and RPLIF models refractory effects through spike-triggered threshold dynamics~\cite{rplif}. Zhang studies reset and refractory periods from the perspective of binary-activated recurrent networks~\cite{zhang2025reset}, while PSN removes reset to obtain parallelizable temporal computations~\cite{psn}. SPRiF retains subtractive membrane reset while preserving spectral memory. Propagating reset into that memory introduces an additional spike-history term, which our analysis derives explicitly.

NiSNN-A writes LIF voltage as the difference between accumulated input and accumulated reset~\cite{nisnna2025}. Its NiLIF update estimates the unknown spike train from the input-only accumulation to obtain a noniterative computation. SPRiF generates spikes by thresholding the actual membrane candidate at each step. The response to a realized spike can then be derived directly from the state equations.

\subsection{Gating and Memory Organization}

Gating controls how information enters and persists in a spiking neuron. GLIF learns gates that combine alternative biological features of membrane leakage, input integration and spike initiation~\cite{glif}. DGN introduces activity-dependent membrane conductance as a dynamic gate that filters incoming signals and suppresses disturbances~\cite{dgn}. These approaches regulate information through nonlinear dynamics. SPRiF uses linear spectral memory with learned projections into the membrane and places the threshold nonlinearity at the output.

Temporal coordination can also be organized at the network level. MPS-SNN views successive timesteps as temporal subnetworks with shared architectures and weights~\cite{mpssnn}. Membrane-potential smoothing and guidance promote consistency across these evaluations. SPRiF focuses on how an input pulse is transformed within one neuron and how an intervening spike changes the drive available to later decisions.

DMP-SNN shares memory within a layer~\cite{sun2026dmp}, whereas SPRiF organizes memory within each neuron. The two designs allocate temporal resources at different levels. SPRiF specifies how five local states receive input, reach the membrane and respond to firing; its matched controls keep the number of states and learned dynamics coefficients fixed while varying temporal modes and reset placement.

These studies motivate separating the temporal response carried by a state from the change imposed on it by firing. In SPRiF, the spectral block defines the basis available to the membrane, while the reset rule determines whether a local spike modifies that basis. A spike can leave the memory coordinates unchanged at discharge and still alter their future trajectory through recurrent current. The analysis distinguishes local memory reset from this feedback, and SI-DMS evaluates their combined effect on delayed decisions.

\section{SPRiF Neuron Model and Analysis}
\label{sec:model}

\subsection{Neuron Formulation}
\label{sec:motivation}
\label{sec:forward}

We define the timing convention using a LIF membrane $v_t$ measured immediately after the current reset. Its candidate voltage, spike and stored voltage are
\begin{equation}
\widetilde v_t=\beta v_{t-1}+I_t,\qquad
z_t=H(\widetilde v_t-\theta),\qquad
v_t=\widetilde v_t-\theta z_t,
\label{eq:lif}
\end{equation}
where $0<\beta<1$, $\theta>0$, and $H(a)=1$ for $a\geq0$ and zero otherwise. Unrolling gives
\begin{equation}
v_t=\beta^{t+1}v_{-1}
+\sum_{j=0}^{t}\beta^{t-j} I_j
-\theta\sum_{j=0}^{t}\beta^{t-j}z_j.
\label{eq:lif_unrolled}
\end{equation}
A unit of current at step $j$ contributes $\beta^{t-j}$ at step $t$, while a spike at the same step contributes $-\theta\beta^{t-j}$. The two histories share the same time course and differ only in sign and scale. SPRiF retains this membrane reset and adds a filtered input history whose coordinates are preserved at discharge.

For an input vector $\mathbf{s}_t$ and a recurrent spiking layer, the current vector is
\begin{equation}
\mathbf I_t=W_{\mathrm{in}}\mathbf s_t+
W_{\mathrm{rec}}\mathbf z_{t-1}+\mathbf b.
\label{eq:current}
\end{equation}
The recurrent term is absent in a feedforward layer. The equations below describe one neuron with its index omitted. Its scalar current $I_t$ is the corresponding component of $\mathbf I_t$. The neuron stores a spectral state $\mathbf x_t\in\R^3$, an auxiliary state $h_t\in\R$, and a firing membrane $u_t^0\in\R$, which evolve as
\begin{equation}
\left\{
\begin{aligned}
\mathbf x_t&=A\mathbf x_{t-1}+BI_t,\\
h_t&=\eta_1h_{t-1}+\bar{\mathbf g}_1^\top\mathbf x_t,\\
\widetilde u_t^0&=\eta_0u_{t-1}^0+h_{t-1}
                    +\mathbf g_0^\top\mathbf x_t,\\
z_t&=H(\widetilde u_t^0-\theta),\\
u_t^0&=\widetilde u_t^0-\theta z_t.
\end{aligned}
\right.
\label{eq:sprif}
\end{equation}
The transition and input vector are
\begin{equation}
A=\begin{bmatrix}
\alpha&0&0\\
0&\rho\cos\omega&-\rho\sin\omega\\
0&\rho\sin\omega&\rho\cos\omega
\end{bmatrix},
\qquad
B=\begin{bmatrix}1-\alpha\\1-\rho\\0\end{bmatrix}.
\label{eq:AB}
\end{equation}
The two directly learned readouts form
\begin{equation}
\bar G=
\begin{bmatrix}\mathbf g_0^\top\\\bar{\mathbf g}_1^\top\end{bmatrix}
\in\R^{2\times3}.
\label{eq:G}
\end{equation}
For finite raw parameters, the constraints are enforced by
\begin{equation}
\begin{aligned}
\alpha&=\sigma(\alpha_{\rm raw}),&
\rho&=\sigma(\rho_{\rm raw}),\\
\omega&=\pi\sigma(\omega_{\rm raw}),&
\eta_i&=\sigma(\eta_{i,{\rm raw}}),\quad i\in\{0,1\}.
\end{aligned}
\label{eq:constraints}
\end{equation}
Here $\sigma$ is the logistic sigmoid. Thus $\alpha,\rho,\eta_i\in(0,1)$ and $\omega\in(0,\pi)$, so every intrinsic mode is contractive. The six entries of $\bar G$ are unconstrained real coefficients, and the threshold is fixed for a task.

Figure~\ref{fig:organization} compares the state organization of LIF and SPRiF. SPRiF provides two routes from $\mathbf x_t$ to firing. The direct projection enters $\widetilde u_t^0$ immediately, while the second updates $h_t$ and reaches the membrane at $t+1$. The membrane therefore reads $h_{t-1}$ at the current step. All intrinsic states are initialized to zero for each independent sequence.

\begin{figure}[!tb]
\centering
\includegraphics[width=0.98\columnwidth]{figure/lif_sprif_overview.png}
\caption{State organization of LIF on the left and SPRiF on the right. LIF integrates input and reset in one membrane. SPRiF separates spectral memory from the auxiliary filter and membrane, with spike-triggered reset confined to the membrane.}
\label{fig:organization}

The filter-to-membrane coupling in Eq.~\eqref{eq:sprif} has unit gain without loss of generality. Any constant gain $\kappa$ can be absorbed into the filter's unconstrained input projection. For a filter $u_t^1=\eta_1u_{t-1}^1+\mathbf g_1^\top\mathbf x_t$ read out as $\kappa u_{t-1}^1$, set
\begin{equation}
h_t=\kappa u_t^1,\qquad
\bar{\mathbf g}_1=\kappa\mathbf g_1,\qquad
h_{-1}=\kappa u_{-1}^1 .
\label{eq:absorption}
\end{equation}
Substitution gives the same forward membrane voltage and spikes for fixed coefficients, including $\kappa=0$. SPRiF therefore learns $\bar{\mathbf g}_1$ directly. Each neuron has five decay or frequency parameters and six projection coefficients.

Each neuron stores five state values $(x^0,x^1,x^2,h,u^0)$. Its eleven learned dynamics coefficients comprise the five raw variables associated with $\alpha,\rho,\omega,\eta_0,\eta_1$ and the six entries of $\bar G$. Thresholds, synaptic weights, biases and output parameters are separate from this local budget.

For a recurrent layer with input width $m$ and hidden width $n$, a dense input matrix, dense recurrent matrix, and one current bias per neuron contribute
\begin{equation}
N_{\rm layer}=mn+n^2+n+11n.
\label{eq:parameters}
\end{equation}
Complete network counts include the task readout and the bias settings of the corresponding layer. A width-$n$ layer stores $5n$ intrinsic values in addition to its spike cache. Its local update costs $O(n)$ per step, while the dense synaptic products cost $O(mn+n^2)$.

\subsection{Temporal Kernel Analysis}
\label{sec:kernels}

The spectral transition has poles
\begin{equation}
\spec(A)=\{\alpha,\rho e^{\mathrm i\omega},
                       \rho e^{-\mathrm i\omega}\}.
\label{eq:poles}
\end{equation}
For a unit impulse $I_0=1$ applied to a zero state at $t=-1$, with zero current thereafter,
\begin{equation}
A^kB=
\begin{bmatrix}
(1-\alpha)\alpha^k\\
(1-\rho)\rho^k\cos(k\omega)\\
(1-\rho)\rho^k\sin(k\omega)
\end{bmatrix},\qquad k\geq0.
\label{eq:impulse}
\end{equation}
The first coordinate retains one sign. In the other two, $\rho$ controls the decay envelope and $\omega$ controls the phase advance. At $\omega=\pi/2$, for example, the cosine coordinate is $1-\rho$ at lag zero and $-(1-\rho)\rho^2$ two steps later. A learned projection can therefore assign opposite weights to the same pulse at different ages.

The auxiliary filter accumulates a second projection of this trajectory. Its response to the same pulse is
\begin{equation}
h_k=\sum_{\ell=0}^{k}\eta_1^{k-\ell}
                \bar{\mathbf g}_1^\top A^\ell B.
\label{eq:h_kernel}
\end{equation}
Let the membrane drive be
\begin{equation}
d_t=\mathbf g_0^\top\mathbf x_t+h_{t-1}.
\label{eq:drive}
\end{equation}
Substituting the spectral and filter responses gives the kernel
\begin{equation}
\begin{aligned}
k_d[k]={}&\mathbf g_0^\top A^kB\\
&{}+\sum_{\ell=0}^{k-1}\eta_1^{k-1-\ell}
                       \bar{\mathbf g}_1^\top A^\ell B ,
\end{aligned}
\label{eq:drive_kernel}
\end{equation}
The sum is empty at $k=0$. Hence $k_d[0]=\mathbf g_0^\top B$, whereas $k_d[1]=\mathbf g_0^\top AB+\bar{\mathbf g}_1^\top B$. The second projection can change the response one step after a pulse without changing its onset. With $\xi$ denoting a unit delay, the transfer function is
\begin{equation}
\mathcal K_d(\xi)=
\left(\mathbf g_0^\top+
\frac{\xi}{1-\eta_1\xi}\bar{\mathbf g}_1^\top\right)
(I_3-\xi A)^{-1}B.
\label{eq:transfer}
\end{equation}
For fixed coefficients and zero initial state, convolving $k_d$ with the realized current sequence gives the exact drive. The membrane then integrates this drive together with its own reset history. For any initial membrane voltage,
\begin{equation}
\begin{aligned}
u_t^0={}&\eta_0^{t+1}u_{-1}^0
+\sum_{j=0}^{t}\eta_0^{t-j}d_j\\
&{}-\theta\sum_{j=0}^{t}\eta_0^{t-j}z_j .
\end{aligned}
\label{eq:membrane_unrolled}
\end{equation}
In Eq.~\eqref{eq:membrane_unrolled}, the membrane has its own leak $\eta_0$, while the drive carries the poles of the spectral block and auxiliary filter unless learned projections cancel them.

The complex pair contributes the quadratic factor $1-2\rho\cos(\omega)\xi+\rho^2\xi^2$ to the denominator of Eq.~\eqref{eq:transfer}. When this factor survives in the readout, a block with only positive real decays and the same auxiliary filter cannot reproduce the kernel at all lags. Its denominator contains only real linear factors. Signed combinations of real decays may change sign, but they do not create the intrinsic oscillatory pole pair. The control in Section~\ref{sec:controls} tests this distinction.

\subsection{Controllability and State Boundedness}
\label{sec:stability}

Current enters two spectral coordinates directly in Eq.~\eqref{eq:AB}, and rotation couples one of them to the third. The three-dimensional state is therefore driven by a scalar current rather than by three independent inputs.

\begin{proposition}[Driven spectral coordinates]
For $\alpha,\rho\in(0,1)$ and $\omega\in(0,\pi)$, the pair $(A,B)$ in Eq.~\eqref{eq:AB} is controllable.
\label{prop:controllability}
\end{proposition}
\begin{IEEEproof}
Let $\mathcal C=[B,AB,A^2B]$. Expanding its determinant gives
\begin{equation}
\begin{aligned}
\det\mathcal C={}&(1-\alpha)(1-\rho)^2\rho\sin\omega\\
&{}\times(\alpha^2-2\alpha\rho\cos\omega+\rho^2).
\end{aligned}
\label{eq:controllability}
\end{equation}
Every factor is positive, since the last factor equals
$|\alpha-\rho e^{\mathrm i\omega}|^2$. Thus $\mathcal C$ has rank three.
\end{IEEEproof}

From zero state, three appropriately chosen scalar inputs can reach any point in the spectral state space before projection.

For fixed parameters and a specified current sequence, define
$\mathbf m_t=[\mathbf x_t^\top,h_t]^\top$. The memory pathway is
\begin{equation}
\mathbf m_t=F\mathbf m_{t-1}+LI_t,
\label{eq:memory_system}
\end{equation}
with
\begin{equation}
F=
\begin{bmatrix}
A&\mathbf0\\
\bar{\mathbf g}_1^\top A&\eta_1
\end{bmatrix},
\qquad
L=
\begin{bmatrix}B\\\bar{\mathbf g}_1^\top B\end{bmatrix}.
\label{eq:memory_matrices}
\end{equation}
The block-triangular structure yields
\begin{equation}
\spec(F)=\{\alpha,\rho e^{\mathrm i\omega},
               \rho e^{-\mathrm i\omega},\eta_1\}.
\label{eq:F_poles}
\end{equation}
Every pole lies strictly inside the unit disk. The learned projection into $h_t$ may amplify a transient, but it cannot remove the asymptotic decay of the underlying modes.

\begin{proposition}[Bounded local states]
Assume fixed finite readouts, finite initial states, $\theta>0$, the ranges in Eq.~\eqref{eq:constraints}, and $|I_t|\leq M$ for all $t\geq0$. Then $\mathbf x_t$, $h_t$, and $u_t^0$ in Eq.~\eqref{eq:sprif} remain bounded.
\label{prop:boundedness}
\end{proposition}
\begin{IEEEproof}
Let $q=\max(\alpha,\rho)<1$. The rotational part of $A^k$ is a rotation scaled by $\rho^k$, so $\|A^k\|_2=q^k$. Summing the geometric series for the forced spectral recurrence gives a uniform bound $X$ on $\|\mathbf x_t\|_2$. Applying the same argument to the filter gives a bound $H_*$ on $|h_t|$, where
\begin{equation}
\begin{aligned}
X &= \|\mathbf x_{-1}\|_2 + \frac{\|B\|_2 M}{1-q},\\
H_* &= |h_{-1}| + \frac{\|\bar{\mathbf g}_1\|_2 X}{1-\eta_1}.
\end{aligned}
\label{eq:local_bounds}
\end{equation}
It follows that $|d_t|\leq \|\mathbf g_0\|_2X+H_*$. Since each spike subtracts at most $\theta$, the expansion in Eq.~\eqref{eq:membrane_unrolled} yields
\begin{equation}
|u_t^0|\leq |u_{-1}^0|+
\frac{\|\mathbf g_0\|_2 X+H_*+\theta}{1-\eta_0}.
\label{eq:u_bound}
\end{equation}
All three bounds are finite.
\end{IEEEproof}

For a prescribed current sequence, a perturbation in the memory and filter coordinates propagates as $\delta\mathbf m_{t+k}=F^k\delta\mathbf m_t$. Poles near the unit circle produce slow decay along this path. If a spike also changes a later current, that input-driven response is added through the same memory kernel.

\subsection{Reset Effects on Memory Dynamics}
\label{sec:reset}

Use superscripts $-$ and $+$ for values immediately before and after the local reset. Equation~\eqref{eq:sprif} gives
\begin{equation}
\mathbf x_t^+=\mathbf x_t^-,
\qquad h_t^+=h_t^-,
\qquad u_t^{0,+}=\widetilde u_t^0-\theta z_t.
\label{eq:reset_identity}
\end{equation}
A spike immediately changes the stored membrane voltage while leaving the four memory and filter coordinates unchanged. For a fixed current sequence, the drive $d_t$ therefore contains no direct contribution from past local resets.

To isolate the effect of resetting memory, consider the control in Eq.~\eqref{eq:memory_reset_control}. After both projections read $\mathbf x_j^-$, a spike at $j$ adds $-\theta\widehat B$ to the stored spectral state, where $\widehat B=B/\|B\|_2$. An input pulse of size $-\theta/\|B\|_2$ would create the same spectral displacement, but it would also enter $h_j$ before the reset. Under a unit pulse, that filter update contributes $\eta_1^{k-1}\bar{\mathbf g}_1^\top B$ to the drive at lag $k\geq1$. Removing this term from Eq.~\eqref{eq:drive_kernel} and scaling by the signed pulse amplitude gives the spike-to-drive kernel $r$. Since the current drive has already been computed, $r[0]=0$. For later lags,
\begin{equation}
r[k]=-\frac{\theta}{\|B\|_2}
\left(k_d[k]-\eta_1^{k-1}\bar{\mathbf g}_1^\top B\right),
\quad k\geq1 .
\label{eq:reset_kernel}
\end{equation}
For zero initial states, superposition in the memory and filter recurrences now gives
\begin{equation}
d_t=\sum_{k=0}^{t} k_d[k]\,I_{t-k}
    +\sum_{k=1}^{t} r[k]\,z_{t-k}.
\label{eq:drive_histories}
\end{equation}
The second sum is the direct contribution of memory reset in \mr{}. In SPRiF, this kernel is identically zero by Eq.~\eqref{eq:reset_identity}. The identities use each model's fixed coefficients and realized currents and spikes; both models still apply the scalar membrane reset.

A spike can also affect memory through recurrent feedback. With the external layer input fixed, a change in the spike vector at $t$ changes the next recurrent current by
\begin{equation}
\delta\mathbf I_{t+1}=W_{\rm rec}\,\delta\mathbf z_t .
\label{eq:recurrent_feedback}
\end{equation}
This change enters the first sum of Eq.~\eqref{eq:drive_histories} through the current-to-drive kernel. It is distinct from the direct memory-reset term in the second sum. SI-DMS tests the joint effect of forced firing, local reset and recurrent propagation on a delayed decision.

\section{Experimental Setup}
\label{sec:setup}

The evaluation tests transfer across temporal tasks, the effects of local state organization, and retention under forced activity. Five benchmarks cover different input representations. Matched controls compare reset placement and temporal modes at fixed local capacity, while SI-DMS tests whether an accurate delayed decision withstands controlled spike interventions.

\subsection{Tasks and Network Architectures}
\label{sec:data}

The benchmarks span sequential images, event-based physiological signals and acoustic recognition. S-MNIST presents each MNIST image~\cite{lecun1998gradient} as 784 scalar inputs, normalized with mean 0.1307 and standard deviation 0.3081. PS-MNIST applies a permutation generated from the run seed and shared between training and test, so seed variation also changes the temporal arrangement of the input. Both tasks use two recurrent layers and a linear readout that averages logits over the full sequence.

QTDB evaluates predictions throughout a sequence. Following Yin \emph{et al.}~\cite{asrnn}, we smooth the two ECG channels of the QT Database~\cite{laguna1997database} and threshold their first differences at $\pm0.03$ to produce four event streams. A recurrent layer predicts six annotation groups at every timestep. Accuracy counts all positions in overlapping windows of length 1301 and stride 650.

The acoustic tasks use distinct input representations and readouts. GSC classifies 12 classes from Speech Commands~\cite{warden2018speech}. Its 40 mel coefficients and their first and second differences provide 120 features per frame, and the recurrent layer pools spikes over 101 frames. SHD receives 700 cochlear spike channels for 20 digit classes~\cite{cramer2022heidelberg}. Its recurrent layer drives 20 nonrecurrent SPRiF output units. The readout sums the softmax of their pre-reset membrane values for $t>10$. Table~\ref{tab:benchmark_config} lists the original and enlarged recurrent-layer widths and training settings.

\subsection{Learning and Statistical Reporting}
\label{sec:training}
\label{sec:statistics}
\label{sec:learning}

The forward pass uses a hard threshold. Backpropagation through time, abbreviated BPTT, replaces its derivative with the multi-Gaussian surrogate~\cite{asrnn}
\begin{equation}
\begin{aligned}
\psi(v)=\gamma\big[&
a_0\mathcal N(v-\theta;0,\sigma_0^2)\\
&-a_1\mathcal N(v-\theta;\mu_1,\sigma_1^2)\\
&-a_1\mathcal N(v-\theta;-\mu_1,\sigma_1^2)\big],
\end{aligned}
\label{eq:surrogate}
\end{equation}
where $\mathcal N(\cdot;\mu,\sigma^2)$ is the normalized Gaussian density,
$\sigma_0=0.5$, $\mu_1=0.5$, $\sigma_1=3.0$,
$a_0=1.15$, $a_1=0.15$, and $\gamma=0.5$.
Gradients pass through recurrent spikes and membrane reset within each BPTT segment, matching the forward computation used by every neuron variant.

All benchmark runs use Adam with the settings in Table~\ref{tab:benchmark_config}. For sequential MNIST, each sequence is divided into segments of 262, 262 and 260 steps, with an optimizer update after each segment. States carry across segment boundaries while gradients are truncated, so forward memory spans the full sequence even though the backward horizon is shorter. GSC uses negative log likelihood on the pooled readout with class-weighted sampling.

Each benchmark decay is initialized from a positive time constant through
\begin{equation}
q=\exp(-1/\tau_q),\qquad q_{\rm raw}=\log\frac{q}{1-q}.
\label{eq:decay_init}
\end{equation}
Frequency is parameterized analogously through $\omega/\pi$. On the MNIST tasks, real-mode and filter time constants are sampled uniformly in steps, with the upper bound for the oscillatory time constant decreasing as frequency increases. QTDB, GSC and SHD use log-uniform time constants. The nominal intervals are listed in Table~\ref{tab:benchmark_config}. All intrinsic states start at zero. Both rows of $\bar G$ are optimized directly; the second uses the product initialization in Eq.~\eqref{eq:absorption} on the benchmarks and starts at zero on SI-DMS.

Each training run is one replicate. New results report mean accuracy and sample standard deviation over seeds $\{0,1,2,42,1111\}$, while published entries retain their source reporting conventions. SI-DMS uses the final checkpoint after 2000 updates, with delays weighted equally within each seed.

\subsection{Comparisons at Fixed Local Capacity}
\label{sec:controls}
\label{sec:baselines}

Baseline comparisons assess performance against existing models, while structural controls test SPRiF's internal design. We rerun TC-LIF~\cite{tclif} and BRF~\cite{brf} on PS-MNIST and SHD, and DMP-SNN~\cite{sun2026dmp} on PS-MNIST with its native layer-shared memory. Table~\ref{tab:main_results} identifies these reruns and reports their network parameter counts.

SPRiF, \mr{} and \rmodes{} use the original network widths in Table~\ref{tab:benchmark_config}, with five states and eleven learned dynamics coefficients per neuron on PS-MNIST, SHD and QTDB. They share partitions, readouts, training budgets, checkpoint rules and seed-specific inputs. Each control changes one memory-pathway choice while retaining the rest of the organization.

\noindent\textit{Reset placement in \mr.}
Compute the current spectral state $\mathbf x_t^-$, both readouts, the auxiliary state and the membrane spike as in SPRiF. After firing, update the spectral state as
\begin{equation}
\begin{aligned}
\widehat B&=\frac{B}{\|B\|_2},\qquad \gamma_{\rm mem}=1,\\
\mathbf x_t^+&=\mathbf x_t^--\gamma_{\rm mem}\theta z_t\widehat B.
\end{aligned}
\label{eq:memory_reset_control}
\end{equation}
The next update starts from $\mathbf x_t^+$. Because $h_t$ was computed from $\mathbf x_t^-$, the displacement reaches the filter at the following step. Its magnitude is $\theta$ per spike and it adds no learned coefficient. The control therefore implements an input-direction memory reset while retaining the same downstream readout and membrane reset.

\noindent\textit{Temporal modes in \rmodes.}
Replace the spectral matrices by
\begin{equation}
A_{\rm real}=\diag(a_1,a_2,a_3),\qquad
B_{\rm real}=\begin{bmatrix}1-a_1\\1-a_2\\1-a_3\end{bmatrix},
\label{eq:real_control}
\end{equation}
where $a_i=\sigma(a_{i,\rm raw})$ are independently learned. Three real decay parameters replace $\alpha,\rho,\omega$; the auxiliary filter, membrane, scalar reset and six readout entries remain unchanged. The first real-mode time constant uses the $\tau_\alpha$ interval, and the other two use independent draws from the $\tau_\rho$ interval. All coordinates are driven. Replacing the rotation by zero would instead leave one coordinate undriven from a zero initial state. This construction provides a capacity-matched all-real basis for testing the real-plus-rotational organization.

\subsection{SI-DMS Task and Intervention Protocol}
\label{sec:sidms}

SI-DMS asks the network to preserve a first cue until a second cue determines a binary match/non-match decision. Each trial begins with a 50-ms baseline and presents two 100-ms cues separated by a delay. Thirty input channels encode left, right and background activity in groups of ten. At each $\Delta t=5$-ms step, active cue channels emit Bernoulli spikes with probability 0.20 and background channels with probability 0.05. A recurrent layer of 64 neurons drives two leaky outputs with a 20-ms time constant; their final values determine the class.

Clean training uses natural firing throughout. For intervention training, $K\in\{0,1,2,4,8\}$ distinct timesteps are sampled uniformly from the delay. At each selected time, ten randomly selected neurons have their membrane candidates set to the threshold plus 0.05. The nominal intervention fraction of 15\% corresponds to ten of 64 neurons, or 15.625\%. The overwrite induces spikes, engages the discharge dynamics and changes subsequent recurrent input. In SPRiF, it leaves the spectral and auxiliary states intact. SI-DMS tests whether a delayed decision withstands forced activity while local spectral memory is preserved.

Both regimes use delays of 200, 400, 800 and 1600 ms, Adam with learning rate 0.003, batches of 256 and 2000 updates. Evaluation adds a 2500-ms delay and uses $K\in\{0,1,2,4,8,16,32,40\}$. Interventions target a fraction $K\Delta t/d$ of the delay timesteps, so a fixed count produces different densities across delays. Short delays probe dense disruption, while long delays probe retention with wider event spacing. Every state organization receives the same overwrite.

For seed $s$, delay $d$, count $K$, and fraction $f$, the paired accuracy loss is
\begin{equation}
\Delta_{s,d}(K,f)=
\Acc_{s,d}(0)-\Acc_{s,d}(K,f).
\label{eq:paired_loss}
\end{equation}
We report clean accuracy, stressed accuracy and their paired difference to assess retention together with task competence. Table~\ref{tab:sidms_results} summarizes $K=40$ at nominal $f=0.15$, averaged over all evaluation delays and separately at 2500~ms. The delay-specific curves show performance at the corresponding intervention densities.

\subsection{Delayed Decisions Under Spike Interventions}
\label{sec:sidms_results}

\subsubsection{Retention after clean training}
Clean training tests retention without prior exposure to interventions. SPRiF, ASRNN and both matched controls solve the unforced task with near-ceiling mean accuracy, providing a common starting point for comparison. As intervention counts increase, SPRiF maintains accurate decisions. ASRNN approaches chance, while the matched controls retain intermediate accuracy (Fig.~\ref{fig:sidms_curves}a). Both memory reset and replacement of the rotational pair therefore increase the sensitivity of an otherwise accurate solution to intervening spikes.

\subsubsection{Learning with interventions}
Intervention training tests task learning and robustness under the same intervention schedule. SPRiF combines high clean accuracy with high stressed accuracy (Fig.~\ref{fig:sidms_curves}b), preserving spectral memory while adapting to the induced recurrent activity. The all-real control has a smaller clean-to-stressed gap after intervention training, although its clean accuracy remains below SPRiF's. Interpreting this gap alongside clean accuracy separates stable performance on a learned task from low accuracy in both conditions.

\subsubsection{Delay and intervention density}
Figure~\ref{fig:sidms_heatmaps} resolves the delay and intervention-density regimes combined in the averaged curves. At the largest count, every timestep of the shortest delay is targeted, whereas fewer than one in ten are targeted at the longest delay. These settings test repeated disruption over a short interval and sparse intervention over a long retention interval, respectively.

Dense short-delay interventions test recovery from repeated activity, while sparse long-delay interventions test retention across extended unforced evolution. SPRiF remains accurate across the displayed grid, including the unseen 2500-ms delay. Its performance therefore supports both recovery under dense interventions and retention over long delays within the evaluated schedule.

\subsection{Implications for Neuron Design}
\label{sec:discussion}

The results connect local memory preservation to network performance. Scalar reset leaves SPRiF's spectral memory unchanged at discharge, while the kernel analysis identifies the additional history term introduced by memory reset. Capacity-matched benchmarks support this separation for temporal classification, and SI-DMS extends the evidence to delayed decisions under forced activity. The two controls show complementary benefits of preserving memory and combining persistence with phase-dependent weighting. Applying an input-direction reset to spectral memory or replacing the rotational pair with real decays reduces classification accuracy at the same local capacity.

\section{Conclusion}
\label{sec:conclusion}

SPRiF combines decaying and rotational memory modes with immediate and delayed readouts, while confining reset to the membrane. The kernel analysis separates input history from the direct effects of memory reset. Capacity-matched controls support the value of memory continuity and the rotational basis for temporal classification. In SI-DMS, the same organization sustains delayed decisions under dense short-delay and sparse long-delay interventions, including the unseen 2500-ms delay. Together, these results support memory continuity and temporal-basis design as complementary principles for compact temporal spiking networks.
