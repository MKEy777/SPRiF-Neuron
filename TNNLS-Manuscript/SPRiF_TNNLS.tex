\begin{abstract}
Temporal tasks with long delays require spiking neural networks (SNNs) to retain information while communicating through spikes. A standard spiking neuron uses one membrane state to integrate input and generate spikes. Reset after each spike can therefore disturb the temporal trace stored in that state. We introduce SPRiF, a five-state neuron that separates a spectral memory from the membrane that reads it. The memory combines a real decay with a damped rotation. Two learned projections drive the membrane: one immediately, the other through an auxiliary filter delayed by one step. Reset acts only on the membrane, leaving the spectral coordinates unchanged at discharge. We derive the input-to-drive kernel and show that resetting spectral memory adds a separate spike-history term. Across five temporal classification benchmarks, our five-seed mean accuracy exceeds the listed reported accuracies on three tasks and transfers across sequential images, ECG signals, speech, and event-based inputs. Matched controls on permuted sequential MNIST and Spiking Heidelberg Digits test reset placement and mode organization. Preserving memory at reset adds 3.37 and 4.56 percentage points over the memory-reset control; retaining the rotational pair adds 2.34 and 2.47 over three driven real modes. On Spike-Intervention Delayed Match-to-Sample, SPRiF reaches 99.42\% accuracy under 40 forced-spike timesteps after clean training and 99.33\% after training with up to eight intervention timesteps. These accuracies are averaged over five delays, including an unseen 2500-ms delay. Impulse responses show heterogeneous learned temporal kernels.
\end{abstract}

\section{Introduction}
\label{sec:introduction}

\IEEEPARstart{T}{emporal} classification requires a model to combine evidence that arrives at different times. In a delayed decision, an early cue may no longer be present when a later cue determines how it should be interpreted. Spiking neural networks (SNNs) must retain that earlier evidence while continuing to communicate through spikes. This requirement makes the neuron's internal dynamics central to temporal processing: they determine both what remains of a past input and what later activity does to that memory.

In the leaky integrate-and-fire (LIF) model, input integration, spike generation and reset all act on the same membrane state. An input pulse and a subsequent spike-induced reset therefore leave traces governed by the same decay. Lengthening the membrane time constant prolongs both traces; it does not separate the retained input from the effect of firing. Moreover, a single exponential decay offers only one temporal response within that state. The design problem is thus not only how long a neuron remembers, but also which temporal responses it retains and how those responses are changed by discharge.

Existing neuron models address these aspects in several ways. Adaptation retains a history of activity~\cite{asrnn,adlif}, while heterogeneous neurons and synapses distribute integration across time scales~\cite{heterogeneity,hetsyn}. Resonant dynamics introduce phase-dependent responses~\cite{izhikevich_rf,brf,drf}, and coupled compartments distribute integration across states~\cite{tclif,dhsnn}. Other approaches modify the interaction between memory and firing. PMSN separates linear hidden compartments from a firing compartment~\cite{pmsn2026}, while DMP-SNN maintains memory shared across a layer~\cite{sun2026dmp}. Reset itself can be softened, adapted or removed~\cite{inflor,arlif,psn}. These approaches provide alternatives to storing all temporal information in a single resetting membrane.

Building on these alternatives, we study how temporal modes and reset placement should be organized within a fixed neuron-local state budget. The temporal basis determines which histories the membrane can use, while reset placement determines whether discharge alters those histories. Their joint organization therefore defines the signal available to a later decision. This motivates a matched comparison that preserves local capacity while varying the memory basis and reset pathway.

We introduce SPRiF, a five-state neuron with a three-coordinate spectral memory, an auxiliary filter and a firing membrane. The spectral memory combines a real decay with a damped rotation, providing persistent and phase-dependent traces of past input. Two learned projections connect this memory to the membrane: one acts immediately, and the other passes through the auxiliary filter with a one-step delay. The second projection can change the response to older input without changing the response at its arrival. A spike resets only the membrane, preserving the spectral and auxiliary coordinates at discharge while leaving recurrent feedback as the network-level route for future state updates.

We examine this design at both the neuron and network levels. The analysis derives the input-to-drive kernel and the spike-history term introduced by resetting spectral memory. Five temporal benchmarks assess transfer across input representations, matched controls test memory reset and temporal modes at fixed local capacity, and Spike-Intervention Delayed Match-to-Sample (SI-DMS) evaluates delayed decisions under forced intervening activity.

The main contributions are as follows:
\begin{enumerate}
\item We propose a five-state spiking neuron that combines a real decay and a damped rotation with immediate and delayed membrane readouts. Scalar membrane reset preserves the local spectral memory at discharge while retaining binary spike generation.
\item We derive the temporal kernel and separate the direct effect of memory reset from recurrent spike feedback. We also establish controllability of the spectral state and bounded local states under the stated parameter and input conditions.
\item We evaluate SPRiF on five temporal benchmarks and test its two design choices with capacity-matched controls. Preserving memory at reset improves accuracy by 3.37 and 4.56 percentage points on PS-MNIST and SHD; retaining the rotational pair improves it by 2.34 and 2.47 points, respectively (Table~\ref{tab:ablation}). In SI-DMS, five-seed mean accuracy at 40 forced-spike timesteps reaches 99.42\% after clean training and 99.33\% after intervention training, averaged over five delays (Table~\ref{tab:sidms_results}).
\end{enumerate}

\section{Related Work}
\label{sec:related}

\subsection{Temporal Dynamics in Spiking Neurons}

Adaptive neurons retain activity in a variable that influences later firing. ASRNN combines adaptive spiking dynamics with recurrent processing for time-domain classification~\cite{asrnn}, while the adLIF family, including the SE-adLIF comparator in Table~\ref{tab:main_results}, exploits adaptation for spatiotemporal processing~\cite{adlif}. SNN-SFA uses spike-frequency adaptation to retain information through a slowly varying firing threshold~\cite{snnsfa}. Earlier spikes leave a trace in neuronal excitability that can support the subsequent recall of temporally dispersed inputs. RadLIF instead combines recurrent connections with an adaptive current driven by subthreshold voltage and spike-triggered increments~\cite{radlif}. These models illustrate two ways to carry activity beyond the membrane time constant: changing the threshold for future firing or changing the current that opposes membrane integration.

DA-LIF introduces independently learnable decays for spatial and temporal tuning~\cite{dalif}. Temporal diversity can also be distributed across neurons: Heterogeneous SNN distributes neuronal parameters to support different integration times~\cite{heterogeneity}, and bimodal time-scale networks explicitly combine populations with short and long time constants~\cite{bimodal}. HetSyn instead assigns time constants to individual synapses, placing temporal integration in synaptic currents~\cite{hetsyn}. Conductance-based models obtain multiple time scales through fast, slow and ultra-slow conductances~\cite{mtc}. These approaches broaden the temporal dynamics available to a network by changing the variables that retain activity and the rates at which they evolve. For SPRiF, the design question also concerns the shape of the retained response. A real decay assigns a fixed-sign trace to an isolated pulse, whereas a rotational pair gives the readout access to its changing phase. Combining these components provides both persistence and phase-dependent weighting within one neuron.

Resonate-and-fire neurons use coupled states whose phase affects the response to a past input~\cite{izhikevich_rf}. BRF develops balanced resonate-and-fire dynamics for trainable spiking networks~\cite{brf}. PRF combines resonant membrane dynamics with a decoupled reset construction for parallel sequence processing~\cite{prf}. 

Compartmental models distribute dynamics across dendritic and somatic states. Dendrify provides reduced models with dendritic integration and local spikes~\cite{dendrify}, TC-LIF couples dendritic and somatic states~\cite{tclif}, and DH-SNN assigns heterogeneous time constants to dendritic branches~\cite{dhsnn}. A close relative of SPRiF is D-RF, whose resonant dendrites feed a somatic readout and whose threshold depends on spike history~\cite{drf}. Its dendrites also evolve without subtractive output reset. SPRiF gives the membrane two learned projections of its spectral states. The second acts through an auxiliary filter one step later. Changing this filtered projection alters later membrane drive without changing its value when an input pulse arrives. The temporal kernel makes this separation between the immediate response and part of the delayed response explicit.

State-space models motivate both the parameterization of spiking dynamics and their organization within a sequence model. SiLIF transfers learnable discretization and logarithmic parameterization to spiking neurons, with a complex-state variant that supports oscillatory regimes~\cite{silif}. SpikingSSMs combine state-space sequence processing with sparse spiking outputs~\cite{spikingssms}. SPRiF specifies a real pole and a complex-conjugate pair directly, then learns how their states reach the membrane through immediate and delayed projections.

\subsection{Reset Mechanisms and Spike History}

PMSN separates the dynamics of its hidden compartments from discharge at its output~\cite{pmsn2026}. Unrolling its diagonalized hidden transition gives a convolution from injected current to the drive at the output compartment. Its parallel output update requires a separate construction, temporal-decoupled reset, which operates on rectified current and discharges integer multiples of the threshold. SPRiF uses a leaky membrane with signed drive and one threshold subtraction per binary spike. This choice gives a closed form for the drive to the membrane while retaining a sequential firing decision. 

Reset design determines how firing changes the state available at later timesteps. Guo \emph{et al.} use a soft reset and membrane-potential rectification to reduce information loss~\cite{inflor}; AR-LIF adapts reset through the relation between input and output~\cite{arlif}. RPLIF models refractory effects through spike-triggered threshold dynamics~\cite{rplif}, while Zhang analyzes reset and refractory periods from the perspective of binary-activated recurrent networks~\cite{zhang2025reset}. PSN removes reset to obtain parallelizable temporal computations~\cite{psn}. SPRiF retains a subtractive membrane reset and analyzes which additional history term appears when that reset is extended to spectral memory.

NiSNN-A writes LIF voltage as the difference between accumulated input and accumulated reset~\cite{nisnna2025}. Its NiLIF update estimates the unknown spike train from the input-only accumulation to obtain a noniterative computation. In SPRiF, spikes are generated by thresholding the actual membrane candidate at each step. The local response to a realized spike can then be derived from the state equations.

\subsection{Gating and Memory Organization}

Gating provides another means of controlling how information enters and persists in a spiking neuron. GLIF learns gating factors that combine alternative biological features of membrane leakage, input integration and spike initiation~\cite{glif}. Its learned gates and membrane parameters enlarge the family of neuronal dynamics that a network can express. DGN introduces activity-dependent membrane conductance as a dynamic gate~\cite{dgn}. This mechanism selectively filters incoming signals and suppresses disturbances, linking neuronal activity to the strength of subsequent input transmission. Both approaches make the regulation of information flow an explicit part of neuron design. SPRiF instead specifies a linear spectral memory and learns its projections into the membrane, with the threshold nonlinearity applied at the output.

Temporal coordination can also be studied at the network level. MPS-SNN views successive timesteps as temporal subnetworks with shared architectures and weights~\cite{mpssnn}. It uses membrane-potential smoothing and guidance between adjacent temporal subnetworks to reduce inconsistencies in their states and outputs. The smoothing mechanism also supports the propagation of information and gradients through time. This perspective emphasizes consistency across successive network evaluations. The SPRiF analysis focuses on the response retained inside each neuron: how an input pulse is transformed over time and how an intervening spike changes the drive available to later decisions.

DMP-SNN shares memory within a layer~\cite{sun2026dmp}, whereas SPRiF organizes memory within each neuron. These choices allocate a network's memory resources at different levels. SPRiF specifies how five local states receive input, communicate with the membrane and respond to firing. Its matched controls keep the number of states and learned dynamics coefficients fixed to compare temporal modes and reset placement.

These studies motivate examining both the temporal response carried by a state and the changes imposed on it by firing. In SPRiF, the spectral block determines the basis available to the membrane. The reset rule determines whether local spikes directly modify that basis state. Local memory reset is distinct from recurrent feedback: a spike can leave the memory coordinates unchanged at discharge and still alter their future trajectory through the recurrent input. The theoretical analysis distinguishes these two paths, while SI-DMS evaluates their combined effect on delayed decisions.

\section{SPRiF Neuron Model and Analysis}
\label{sec:model}

\subsection{Neuron Formulation}
\label{sec:motivation}
\label{sec:forward}

To fix the timing convention, let $v_t$ be a LIF membrane immediately after the current reset. Its candidate, spike, and stored voltage are
\begin{equation}
\widetilde v_t=\beta v_{t-1}+I_t,\qquad
z_t=H(\widetilde v_t-\theta),\qquad
v_t=\widetilde v_t-\theta z_t,
\label{eq:lif}
\end{equation}
where $0<\beta<1$, $\theta>0$, and $H(a)=1$ for $a\geq0$ and zero otherwise. Unrolling gives
\begin{equation}
v_t=\beta^{t+1}v_{-1}
+\sum_{j=0}^{t}\beta^{t-j} I_j
-\theta\sum_{j=0}^{t}\beta^{t-j}z_j.
\label{eq:lif_unrolled}
\end{equation}
A unit of current at step $j$ contributes $\beta^{t-j}$ at step $t$. A spike at the same step contributes $-\theta\beta^{t-j}$. The two contributions differ in sign and scale but have the same time course. SPRiF retains membrane reset and gives the membrane access to a second history, a filtered record of the input current whose coordinates are preserved at discharge.

For an input vector $\mathbf{s}_t$ and a recurrent spiking layer, the current vector is
\begin{equation}
\mathbf I_t=W_{\mathrm{in}}\mathbf s_t+
W_{\mathrm{rec}}\mathbf z_{t-1}+\mathbf b.
\label{eq:current}
\end{equation}
The recurrent term is omitted for a feedforward layer. The equations below concern one neuron and suppress its index. Its current $I_t$ is the corresponding component of $\mathbf I_t$, and it stores $\mathbf x_t\in\R^3$, $h_t\in\R$, and $u_t^0\in\R$:
\begin{equation}
\left\{
\begin{aligned}
\mathbf x_t&=A\mathbf x_{t-1}+BI_t,\\
h_t&=\eta_1h_{t-1}+\bar{\mathbf g}_1^\top\mathbf x_t,\\
\widetilde u_t^0&=\eta_0u_{t-1}^0+h_{t-1}
                    +\mathbf g_0^\top\mathbf x_t,\\
z_t&=H(\widetilde u_t^0-\theta),\\
u_t^0&=\widetilde u_t^0-\theta z_t.
\end{aligned}
\right.
\label{eq:sprif}
\end{equation}
The transition and input vector are
\begin{equation}
A=\begin{bmatrix}
\alpha&0&0\\
0&\rho\cos\omega&-\rho\sin\omega\\
0&\rho\sin\omega&\rho\cos\omega
\end{bmatrix},
\qquad
B=\begin{bmatrix}1-\alpha\\1-\rho\\0\end{bmatrix}.
\label{eq:AB}
\end{equation}
The two directly learned readouts form
\begin{equation}
\bar G=
\begin{bmatrix}\mathbf g_0^\top\\\bar{\mathbf g}_1^\top\end{bmatrix}
\in\R^{2\times3}.
\label{eq:G}
\end{equation}
For finite raw parameters, the constraints are enforced by
\begin{equation}
\begin{aligned}
\alpha&=\sigma(\alpha_{\rm raw}),&
\rho&=\sigma(\rho_{\rm raw}),\\
\omega&=\pi\sigma(\omega_{\rm raw}),&
\eta_i&=\sigma(\eta_{i,{\rm raw}}),\quad i\in\{0,1\}.
\end{aligned}
\label{eq:constraints}
\end{equation}
Here $\sigma$ is the logistic sigmoid. Thus $\alpha,\rho,\eta_i\in(0,1)$ and $\omega\in(0,\pi)$. The six entries of $\bar G$ are unconstrained real coefficients. The threshold is a fixed task setting.

Figure~\ref{fig:organization} contrasts the state organization of LIF and SPRiF. In SPRiF, two routes connect $\mathbf x_t$ to firing. The direct projection enters $\widetilde u_t^0$ immediately. The second projection updates $h_t$, which first enters the membrane at $t+1$. At the current step the membrane reads $h_{t-1}$. All intrinsic states start at zero for an independent sequence.

\begin{figure}[!t]
\centering
\includegraphics[width=0.98\columnwidth]{figure/lif_sprif_overview.png}
\caption{State organization of LIF (left) and SPRiF (right). LIF integrates input and reset in one membrane. SPRiF separates spectral memory from the auxiliary filter and membrane, with spike-triggered reset confined to the membrane.}
\label{fig:organization}
\end{figure}

The filter-to-membrane coupling in Eq.~\eqref{eq:sprif} has unit gain. A separate constant gain $\kappa$ would be redundant with the unconstrained input projection of the filter. For a filter $u_t^1=\eta_1u_{t-1}^1+\mathbf g_1^\top\mathbf x_t$ read out as $\kappa u_{t-1}^1$, set
\begin{equation}
h_t=\kappa u_t^1,\qquad
\bar{\mathbf g}_1=\kappa\mathbf g_1,\qquad
h_{-1}=\kappa u_{-1}^1 .
\label{eq:absorption}
\end{equation}
Substitution gives the same forward membrane voltage and spikes for fixed coefficients, including at $\kappa=0$. SPRiF learns $\bar{\mathbf g}_1$ directly. This leaves five decay or frequency parameters and six projection coefficients per neuron.

Each neuron stores $(x^0,x^1,x^2,h,u^0)$, for five state values. It learns the five raw variables associated with $\alpha,\rho,\omega,\eta_0,\eta_1$ and six entries of $\bar G$, for eleven dynamics coefficients. Thresholds are fixed, and synaptic weights, biases, and output parameters are separate.

For a recurrent layer with input width $m$ and hidden width $n$, a dense input matrix, dense recurrent matrix, and one current bias per neuron contribute
\begin{equation}
N_{\rm layer}=mn+n^2+n+11n.
\label{eq:parameters}
\end{equation}
Complete network counts include the task readout and use the bias settings of the corresponding layer. A width-$n$ layer stores $5n$ intrinsic state values in addition to its spike cache. Its local update takes $O(n)$ operations per step, while the dense synaptic products take $O(mn+n^2)$.

\subsection{Temporal Kernel Analysis}
\label{sec:kernels}

The poles of the spectral transition are
\begin{equation}
\spec(A)=\{\alpha,\rho e^{\mathrm i\omega},
                       \rho e^{-\mathrm i\omega}\}.
\label{eq:poles}
\end{equation}
For a unit impulse $I_0=1$, zero state at $t=-1$, and zero later current,
\begin{equation}
A^kB=
\begin{bmatrix}
(1-\alpha)\alpha^k\\
(1-\rho)\rho^k\cos(k\omega)\\
(1-\rho)\rho^k\sin(k\omega)
\end{bmatrix},\qquad k\geq0.
\label{eq:impulse}
\end{equation}
The first coordinate retains one sign. In the other two, $\rho$ sets the decay per step and $\omega$ sets the phase advance. For example, at $\omega=\pi/2$ the cosine coordinate equals $1-\rho$ at lag zero and $-(1-\rho)\rho^2$ two steps later. A projection onto that coordinate can therefore give the same pulse opposite weights according to its age.

The auxiliary filter accumulates a second projection of this trajectory. For the same pulse its response is
\begin{equation}
h_k=\sum_{\ell=0}^{k}\eta_1^{k-\ell}
                \bar{\mathbf g}_1^\top A^\ell B.
\label{eq:h_kernel}
\end{equation}
Write the membrane drive as
\begin{equation}
d_t=\mathbf g_0^\top\mathbf x_t+h_{t-1}.
\label{eq:drive}
\end{equation}
Substituting the spectral and filter responses gives the kernel
\begin{equation}
\begin{aligned}
k_d[k]={}&\mathbf g_0^\top A^kB\\
&{}+\sum_{\ell=0}^{k-1}\eta_1^{k-1-\ell}
                       \bar{\mathbf g}_1^\top A^\ell B ,
\end{aligned}
\label{eq:drive_kernel}
\end{equation}
The sum is empty at $k=0$. In particular, $k_d[0]=\mathbf g_0^\top B$ and $k_d[1]=\mathbf g_0^\top AB+\bar{\mathbf g}_1^\top B$. Adjusting the second projection can change the response one step after a pulse while leaving its onset unchanged. Writing $\xi$ for a unit delay gives the transfer function
\begin{equation}
\mathcal K_d(\xi)=
\left(\mathbf g_0^\top+
\frac{\xi}{1-\eta_1\xi}\bar{\mathbf g}_1^\top\right)
(I_3-\xi A)^{-1}B.
\label{eq:transfer}
\end{equation}
For fixed coefficients and zero initial state, convolving $k_d$ with the realized current sequence gives the exact drive. The membrane then integrates this drive and its own reset history. For any initial membrane voltage,
\begin{equation}
\begin{aligned}
u_t^0={}&\eta_0^{t+1}u_{-1}^0
+\sum_{j=0}^{t}\eta_0^{t-j}d_j\\
&{}-\theta\sum_{j=0}^{t}\eta_0^{t-j}z_j .
\end{aligned}
\label{eq:membrane_unrolled}
\end{equation}
Equation~\eqref{eq:membrane_unrolled} assigns the membrane its own leak $\eta_0$. The drive that precedes this integration has the poles of the spectral block and the auxiliary filter, subject to cancellation by the learned projections.

The complex pair contributes the quadratic factor $1-2\rho\cos(\omega)\xi+\rho^2\xi^2$ to the denominator of Eq.~\eqref{eq:transfer}. If this factor survives in the readout, a block containing only positive real decays and the same auxiliary filter cannot reproduce the kernel at all lags. Its denominator has only real linear factors. The distinction is an intrinsic oscillatory mode, since signed sums of real decays can themselves change sign. Section~\ref{sec:controls} defines a control with three driven real modes.

\subsection{Controllability and State Boundedness}
\label{sec:stability}

Current enters two spectral coordinates directly (Eq.~\eqref{eq:AB}). Rotation couples one of them to the third. The resulting three-dimensional state can be reached with a scalar current.

\begin{proposition}[Driven spectral coordinates]
For $\alpha,\rho\in(0,1)$ and $\omega\in(0,\pi)$, the pair $(A,B)$ in Eq.~\eqref{eq:AB} is controllable.
\label{prop:controllability}
\end{proposition}
\begin{IEEEproof}
Let $\mathcal C=[B,AB,A^2B]$. Expanding its determinant gives
\begin{equation}
\begin{aligned}
\det\mathcal C={}&(1-\alpha)(1-\rho)^2\rho\sin\omega\\
&{}\times(\alpha^2-2\alpha\rho\cos\omega+\rho^2).
\end{aligned}
\label{eq:controllability}
\end{equation}
Every factor is positive, since the last factor equals
$|\alpha-\rho e^{\mathrm i\omega}|^2$. Thus $\mathcal C$ has rank three.
\end{IEEEproof}

From zero state, three appropriately chosen scalar inputs can therefore reach any point in the spectral state space before projection.

For fixed parameters and a specified current sequence, define
$\mathbf m_t=[\mathbf x_t^\top,h_t]^\top$. The memory pathway is
\begin{equation}
\mathbf m_t=F\mathbf m_{t-1}+LI_t,
\label{eq:memory_system}
\end{equation}
with
\begin{equation}
F=
\begin{bmatrix}
A&\mathbf0\\
\bar{\mathbf g}_1^\top A&\eta_1
\end{bmatrix},
\qquad
L=
\begin{bmatrix}B\\\bar{\mathbf g}_1^\top B\end{bmatrix}.
\label{eq:memory_matrices}
\end{equation}
The block-triangular structure gives
\begin{equation}
\spec(F)=\{\alpha,\rho e^{\mathrm i\omega},
               \rho e^{-\mathrm i\omega},\eta_1\}.
\label{eq:F_poles}
\end{equation}
Each pole is strictly inside the unit disk. The learned projection into $h_t$ can amplify a transient even though every mode decays.

\begin{proposition}[Bounded local states]
Assume fixed finite readouts, finite initial states, $\theta>0$, the ranges in Eq.~\eqref{eq:constraints}, and $|I_t|\leq M$ for all $t\geq0$. Then $\mathbf x_t$, $h_t$, and $u_t^0$ in Eq.~\eqref{eq:sprif} remain bounded.
\label{prop:boundedness}
\end{proposition}
\begin{IEEEproof}
Let $q=\max(\alpha,\rho)<1$. The rotational part of $A^k$ is a rotation scaled by $\rho^k$, so $\|A^k\|_2=q^k$. Summing the geometric series for the forced spectral recurrence gives a uniform bound $X$ on $\|\mathbf x_t\|_2$. Applying the same argument to the filter gives a bound $H_*$ on $|h_t|$, where
\begin{equation}
\begin{aligned}
X &= \|\mathbf x_{-1}\|_2 + \frac{\|B\|_2 M}{1-q},\\
H_* &= |h_{-1}| + \frac{\|\bar{\mathbf g}_1\|_2 X}{1-\eta_1}.
\end{aligned}
\label{eq:local_bounds}
\end{equation}
It follows that $|d_t|\leq \|\mathbf g_0\|_2X+H_*$. Since each spike subtracts at most $\theta$, the expansion in Eq.~\eqref{eq:membrane_unrolled} yields
\begin{equation}
|u_t^0|\leq |u_{-1}^0|+
\frac{\|\mathbf g_0\|_2 X+H_*+\theta}{1-\eta_0}.
\label{eq:u_bound}
\end{equation}
All three bounds are finite.
\end{IEEEproof}

For a prescribed current sequence, a perturbation within the memory and filter coordinates propagates as $\delta\mathbf m_{t+k}=F^k\delta\mathbf m_t$. Poles near the unit circle permit slow decay along this path. If a spike changes a subsequent current, an additional input-driven response must be included.

\subsection{Reset Effects on Memory Dynamics}
\label{sec:reset}

Use superscripts $-$ and $+$ for values immediately before and after the current local reset. Equation~\eqref{eq:sprif} gives
\begin{equation}
\mathbf x_t^+=\mathbf x_t^-,
\qquad h_t^+=h_t^-,
\qquad u_t^{0,+}=\widetilde u_t^0-\theta z_t.
\label{eq:reset_identity}
\end{equation}
A spike changes stored voltage immediately. All four memory and filter coordinates have zero reset increment, so for a given current sequence the drive $d_t$ contains no direct contribution from past local resets.

To see what changes when a spike also acts on memory, consider the control in Eq.~\eqref{eq:memory_reset_control}. After both projections have read $\mathbf x_j^-$, a spike at $j$ adds $-\theta\widehat B$ to the stored spectral state, where $\widehat B=B/\|B\|_2$. An input pulse of size $-\theta/\|B\|_2$ would produce the same spectral displacement. Its timing within the step would differ, however, because an input pulse enters $h_j$ before the reset occurs. Under a unit pulse, that filter update contributes $\eta_1^{k-1}\bar{\mathbf g}_1^\top B$ to the drive at lag $k\geq1$. Removing this contribution from Eq.~\eqref{eq:drive_kernel} and scaling by the signed pulse amplitude gives the kernel $r$ from a spike to the membrane drive. The current drive has already been computed, so $r[0]=0$. At later lags,
\begin{equation}
r[k]=-\frac{\theta}{\|B\|_2}
\left(k_d[k]-\eta_1^{k-1}\bar{\mathbf g}_1^\top B\right),
\quad k\geq1 .
\label{eq:reset_kernel}
\end{equation}
For zero initial states, superposition in the memory and filter recurrences now gives
\begin{equation}
d_t=\sum_{k=0}^{t} k_d[k]\,I_{t-k}
    +\sum_{k=1}^{t} r[k]\,z_{t-k}.
\label{eq:drive_histories}
\end{equation}
The second sum is the direct contribution of memory reset in \mr{}. In SPRiF its kernel is identically zero by Eq.~\eqref{eq:reset_identity}. Each identity uses the model's own fixed coefficients and realized currents and spikes. The membrane in both models still receives its scalar reset.

A spike can also return through the network. Holding the external layer input fixed, a change in the spike vector at $t$ changes the next recurrent current by
\begin{equation}
\delta\mathbf I_{t+1}=W_{\rm rec}\,\delta\mathbf z_t .
\label{eq:recurrent_feedback}
\end{equation}
This change enters the first sum of Eq.~\eqref{eq:drive_histories} through the same kernel as any other current. It is distinct from the direct memory reset in the second sum. SI-DMS tests the joint effect of overwriting membrane candidates, firing, reset and recurrent propagation on a delayed decision.

\section{Experimental Setup}
\label{sec:setup}

The evaluation separates three questions: whether SPRiF supports temporal classification, whether its state organization matters at fixed local capacity, and whether a learned delayed decision survives changes in intervening spiking activity. The benchmarks address task performance; matched controls test reset placement and temporal modes. SI-DMS then examines retention under an explicit activity perturbation, with clean-task competence and intervention density considered separately.

\subsection{Tasks and Network Architectures}
\label{sec:data}

The benchmarks span sequential image classification, event-based physiological signals and acoustic recognition. S-MNIST presents each MNIST image~\cite{lecun1998gradient} as 784 scalar inputs, normalized with mean 0.1307 and standard deviation 0.3081. PS-MNIST removes the original pixel ordering through a permutation generated from the run seed and shared between training and test. Its seed variability therefore includes changes in the temporal arrangement of the input. Both tasks use two recurrent layers and a linear readout that averages logits over the full sequence.

QTDB tests predictions throughout a sequence rather than a single final class. Four event streams are derived from two ECG channels of the QT Database~\cite{laguna1997database} by smoothing each channel and thresholding its first differences at $\pm0.03$. A recurrent layer predicts six annotation groups at every timestep. Accuracy counts all positions in overlapping windows of length 1301 and stride 650. The generator lists record \emph{sel16483} in both partitions; the reported score therefore refers to the supplied preprocessed partition.

The acoustic tasks use different input representations and readouts. GSC classifies 12 classes from Speech Commands~\cite{warden2018speech}. Forty mel coefficients and their first and second differences yield 120 features per frame; the recurrent layer pools spikes over 101 frames. SHD instead receives 700 cochlear spike channels for 20 digit classes~\cite{cramer2022heidelberg}. Its recurrent layer drives 20 nonrecurrent SPRiF output units, and the readout sums the softmax of their pre-reset membrane values over indices $t>10$. \subsection{Learning and Statistical Reporting}
\label{sec:training}
\label{sec:statistics}
\label{sec:learning}

The forward pass uses a hard threshold. During backpropagation through time (BPTT), its derivative is replaced by the multi-Gaussian surrogate~\cite{asrnn}
\begin{equation}
\begin{aligned}
\psi(v)=\gamma\big[&
a_0\mathcal N(v-\theta;0,\sigma_0^2)\\
&-a_1\mathcal N(v-\theta;\mu_1,\sigma_1^2)\\
&-a_1\mathcal N(v-\theta;-\mu_1,\sigma_1^2)\big],
\end{aligned}
\label{eq:surrogate}
\end{equation}
where $\mathcal N(\cdot;\mu,\sigma^2)$ is the normalized Gaussian density,
$\sigma_0=0.5$, $\mu_1=0.5$, $\sigma_1=3.0$,
$a_0=1.15$, $a_1=0.15$, and $\gamma=0.5$.
Gradients pass through recurrent spikes and membrane reset within each BPTT segment.

All benchmark runs use Adam with the settings in Table~\ref{tab:benchmark_config}. For sequential MNIST, each sequence is divided into segments of 262, 262 and 260 steps, with an optimizer update after each segment. State values carry across boundaries, but gradients do not. These tasks therefore test learning with persistent forward states and a truncated backward horizon. GSC uses negative log likelihood on the pooled readout with class-weighted sampling.

Each benchmark decay is initialized from a positive time constant:
\begin{equation}
q=\exp(-1/\tau_q),\qquad q_{\rm raw}=\log\frac{q}{1-q}.
\label{eq:decay_init}
\end{equation}
Frequency is parameterized analogously through $\omega/\pi$. On the MNIST tasks, real-mode and filter time constants are sampled uniformly in steps; the upper bound for the oscillatory time constant decreases with frequency. QTDB, GSC and SHD use log-uniform time constants. The nominal intervals are listed in Table~\ref{tab:benchmark_config}. All intrinsic states start at zero. Both rows of $\bar G$ are optimized directly; the second uses the product initialization in Eq.~\eqref{eq:absorption} on the benchmarks and starts at zero on SI-DMS.

One training run is one replicate. New results report mean accuracy and sample standard deviation over seeds $\{0,1,2,42,1111\}$; published entries retain their original reporting conventions. For S-MNIST, PS-MNIST, QTDB and SHD, each run contributes its highest test accuracy across epochs, so the reported test split also selects the checkpoint. GSC contributes its highest validation accuracy. These selection rules must be considered when comparing with external reports. SI-DMS uses the final checkpoint after 2000 updates, with delays weighted equally within each seed.

\subsection{Comparisons at Fixed Local Capacity}
\label{sec:controls}
\label{sec:baselines}

The external comparisons and structural controls serve different purposes. TC-LIF~\cite{tclif} and BRF~\cite{brf} were rerun on PS-MNIST and SHD. DMP-SNN~\cite{sun2026dmp} was rerun on PS-MNIST using its native architecture with layer-shared memory. Table~\ref{tab:main_results} distinguishes our reruns from published scores and gives separate parameter counts where network sizes differ. These comparisons place SPRiF among existing models; the following controls address its internal design.

SPRiF, \mr{} and \rmodes{} have the same layer widths, five states and eleven learned dynamics coefficients per neuron on PS-MNIST and SHD. Partitions, network readouts, training budgets, checkpoint rules and seed-specific inputs are shared. Each control changes one aspect of the memory pathway while retaining the remaining organization.

\noindent\textit{Reset placement (\mr).}
Compute the current spectral state $\mathbf x_t^-$, both readouts, the auxiliary state and the membrane spike as in SPRiF. After firing, additionally update
\begin{equation}
\begin{aligned}
\widehat B&=\frac{B}{\|B\|_2},\qquad \gamma_{\rm mem}=1,\\
\mathbf x_t^+&=\mathbf x_t^--\gamma_{\rm mem}\theta z_t\widehat B.
\end{aligned}
\label{eq:memory_reset_control}
\end{equation}
The next update starts from $\mathbf x_t^+$. Because $h_t$ was computed from $\mathbf x_t^-$, the displacement enters the filter at the following step. Its magnitude is $\theta$ per spike and it adds no learned coefficient. This control implements the specified input-direction memory reset while retaining the same downstream readout and membrane reset.

\noindent\textit{Temporal modes (\rmodes).}
Replace the spectral matrices by
\begin{equation}
A_{\rm real}=\diag(a_1,a_2,a_3),\qquad
B_{\rm real}=\begin{bmatrix}1-a_1\\1-a_2\\1-a_3\end{bmatrix},
\label{eq:real_control}
\end{equation}
where $a_i=\sigma(a_{i,\rm raw})$ are independently learned. Three real decay parameters replace $\alpha,\rho,\omega$; the auxiliary filter, membrane, scalar reset and six readout entries are retained. The first real-mode time constant uses the $\tau_\alpha$ interval, and the other two use independent draws from the $\tau_\rho$ interval. All coordinates are driven. Setting the rotation angle to zero instead would leave one coordinate undriven from a zero initial state. This construction therefore provides a capacity-matched all-real temporal basis against which the real-plus-rotational organization can be evaluated.

\subsection{SI-DMS Task and Intervention Protocol}
\label{sec:sidms}

SI-DMS requires the network to preserve a first cue until a second cue determines a binary match/non-match decision. Each trial begins with a 50-ms baseline and presents two 100-ms cues separated by a delay. Thirty input channels encode left, right and background activity in groups of ten. At each $\Delta t=5$-ms step, active cue channels emit a Bernoulli spike with probability 0.20 and background activity has probability 0.05. A recurrent layer of 64 neurons drives two leaky outputs with a 20-ms time constant; their final values determine the class.

Clean training uses natural firing throughout. Intervention training samples $K\in\{0,1,2,4,8\}$ distinct timesteps uniformly from the delay. At each selected time, ten randomly selected neurons have their membrane candidates set to the current threshold plus 0.05. The nominal intervention fraction is 15\%, corresponding to ten of 64 neurons (15.625\%). The overwrite induces spikes, engages the model's discharge dynamics and alters subsequent recurrent input. In SPRiF, it leaves the current spectral and auxiliary states intact. SI-DMS therefore evaluates the recurrent decision process when intervening activity must be absorbed without overwriting the local spectral memory.

Both regimes use delays of 200, 400, 800 and 1600 ms, Adam with learning rate 0.003, batches of 256 and 2000 updates. Evaluation adds a 2500-ms delay and uses $K\in\{0,1,2,4,8,16,32,40\}$. This is a count-based intervention schedule: for a delay $d$, the fraction of delay timesteps targeted is $K\Delta t/d$. Short delays therefore provide dense intervention stress, whereas long delays probe retention with wider event spacing. The same overwrite is applied to every state organization.

For seed $s$, delay $d$, count $K$, and fraction $f$, the paired accuracy loss is
\begin{equation}
\Delta_{s,d}(K,f)=
\Acc_{s,d}(0)-\Acc_{s,d}(K,f).
\label{eq:paired_loss}
\end{equation}
We report clean accuracy, stressed accuracy and their paired difference to connect retention with task competence. Table~\ref{tab:sidms_results} summarizes $K=40$ at nominal $f=0.15$, averaged over all evaluation delays and separately at 2500~ms. Delay-specific curves show the corresponding intervention-density regimes.

The reset comparison links this observation to a specific operation. In \mr{}, each discharge adds a spike-history term to the membrane drive even when incoming current is held fixed (Eq.~\eqref{eq:drive_histories}). The mode comparison concerns temporal selectivity rather than memory duration alone. A rotational pair can assign different weights to the same input at different ages through phase, while its decay envelope controls persistence. The driven real-mode control also supplies several time scales, and signed combinations of its responses can change sign; the relevant distinction is the intrinsic oscillatory mode identified by Eq.~\eqref{eq:transfer}. \subsection{Implications for Neuron Design}
\label{sec:discussion}

The evidence connects a precise local property to network-level utility. Scalar reset leaves SPRiF's spectral memory unchanged at discharge, and the kernel analysis identifies the additional history term introduced when memory is also reset. Capacity-matched benchmarks and SI-DMS show that this organization is useful in both standard temporal classification and delayed decisions under forced activity. Together with the all-real comparison, the results assign a clear role to the temporal basis: preserving memory at discharge and combining persistence with phase-dependent weighting gives the network a more effective local representation than either resetting the full state or replacing the rotational pair with real decays.

\section{Conclusion}
\label{sec:conclusion}

SPRiF organizes neuron-local memory into decaying and rotational modes, read through immediate and delayed projections, while confining reset to the membrane. The analysis makes the resulting temporal kernel and reset-history effect explicit. At fixed local capacity, this organization improves temporal classification over both the full-state reset and all-real controls. SI-DMS further shows that SPRiF learns delayed decisions that remain accurate under intervening forced activity across the tested delay schedules. The results support separating memory from discharge and choosing its temporal basis jointly as a compact design principle for temporal spiking networks.
