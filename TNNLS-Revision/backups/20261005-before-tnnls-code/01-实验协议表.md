\[
\begin{aligned}

### C1. S-MNIST 与 PS-MNIST

**代码事实：**

- 加载 torchvision MNIST 的官方 train/test 文件，没有验证集划分。
- `ToTensor» 后用固定均值 0.1307、标准差 0.3081 归一化，再按像素展开为 784×1。S-MNIST 不是 28 步逐行输入。
- PS-MNIST 以 `torch.manual_seed(seed); torch.randperm(784)» 生成置换，同一次运行的训练和测试使用同一置换；跨种子置换改变。
- 测试：将最后隐藏层脉冲经线性读出得到逐步 logits，取整个序列的时间均值，argmax 得类别。warm-up 默认 0。
- 训练：784 步分为 **262、262、260** 三块；每块对平均 logits 计算一次交叉熵，独立 zero_grad/backward/optimizer.step。数值状态跨块保留，每块结束 detach，包括上一脉冲缓存；每个 batch 开始重新初始化状态。
- 训练准确率用三个 chunk logits 的等权均值；测试用全序列逐步均值，两者并非严格相同的加权汇总。训练途中三个 chunk 还使用先后更新的参数。
- 入口每个 epoch 测试，并按最高 test accuracy 保存模型。`--tbptt-len 0» 的帮助文字声称完整 BPTT，但当前循环会产生零步长错误，正式配置只使用已核实的 262。

**新实验规则：**

- 保留归一化、网络、chunk 更新方式及完整序列评价方式，并如实写出每个 minibatch 的三次更新。对所有受控比较使用相同流程。
- 独立固定划分 seed=20261005，从官方训练池抽取 5,000 张作为验证集，其余作为训练集；官方 test 文件保持独立。标准文件下预期为 55,000/5,000/10,000，实际读取数量尚未核实。
- 划分与模型训练 seed 分离，所有模型、所有五种子共用同一划分。PS 置换按运行 seed 生成并保存，共同模型使用相同置换。
- 每 epoch 在完整序列验证准确率上选模，取首次达到最高值的 checkpoint；训练结束后只对该 checkpoint 做最终测试。

### C2. QTDB/ECG

**代码事实：**

- 训练入口读取外部 MAT 文件，x 为事件输入，y 经 one-hot argmax 得到类别。时间差由工具函数计算，但训练入口丢弃该结果，状态每个索引推进一次。
- 提供的生成器声明采样率 250 Hz、窗口 1301 点、步长 650 点，约一半窗口重叠。它不核对 `record.fs»，也不主动重采样；4 ms/步只在原记录确为 250 Hz 时成立。
- 取两个 `p_signal» 通道，逐窗口用 Savitzky–Golay（窗口 5、阶数 3）平滑；一阶差分 ≥0.03 或 ≤−0.03 编为正、负事件，形成四路输入。源码没有幅值归一化。
- 标签来源为 `atr» 注释符号：N/“.”→0，L→1，R→2，V→3，A/a→4，其余列举符号及未知符号→5；首个注释前默认为 0，标签延续至下一注释。该源码定义是六组心搏注释标签，不能直接写成 P/QRS/T 波形分割类别或标准六类 AAMI 分类。
- 输出逐时间步线性 logits。损失为全部 B×T 时间点的平均交叉熵再乘 T；默认无 masking、无类别权重。accuracy 分母为全部窗口时间点数，重叠位置在不同窗口中重复计数。
- 生成器声明训练记录 104 项、测试记录 9 项；**sel16483 同时在两列表中**，生成循环会将它放入两套数据。合并去重后为 112 个声明 ID，并非本次实际读取到 112 条记录。
- 原入口按最高 test accuracy 选模，没有验证集。生成器未将 record ID、窗口起点保存进 MAT，也会跳过读取失败的记录，因此当前 MAT 路径不能单独证明分组划分。

**新实验规则及待核实：**

- 保留测试 ID 集合：sel102、sel1460、sel1468、sel1469、sel1505、sel1513、sel1519、sel1534、sel16483；从训练池移除测试 ID。若全部声明记录有效，训练候选池为 103 条；实际成功读取数待核实。
- 在生成窗口前，对有效训练记录按固定 seed=20261005 划出 ceil(10%) 作为验证记录。保存 train/val/test ID 清单；任何重叠窗口只归所属记录所在集合。若存在同一受试者多记录，须先核实并按受试者合并分组；不能宣称源码已经做到受试者隔离。
- 保存原记录 fs、物理单位、注释类型、类别映射、窗口起点及每类数量。固定窗口/stride=1301/650；只在 fs 校验通过后采用 4 ms/步。缺失或错误注释记录单列，不能静默改变评价池。

### C3. GSC

**代码事实：**

- 下载脚本指定 Speech Commands v0.02；当前实际数据和清单未随代码提供。
- 十个关键词依次为 yes/no/up/down/left/right/on/off/stop/go，再加 `_silence_»、`_unknown_»，共 12 类；其他非下划线命令目录映射至 unknown。

时间常数单位是**离散步**；q=exp(−1/τ)，经 clamp(q,1e−4,1−1e−4) 和 logit 存入 raw 参数。ω 均在角频率区间均匀抽样，再将 ω/π 做同样的 logit 映射；训练时用 sigmoid 恢复 decay、π×sigmoid 恢复 ω。

S/PS：τα、两项 τη 线性均匀抽样。振荡衰减不是独立 U[2,40]，其实际规则为：

\[
\begin{aligned}
r_\omega&=\frac{\omega-\omega_{\min}}{\omega_{\max}-\omega_{\min}+10^{-5}},\\
\tau_{\rho,\mathrm{hi}}&=\max\{\tau_{\rho,\max}
-r_\omega(\tau_{\rho,\max}-1.5\tau_{\rho,\min}),\
\tau_{\rho,\min}+0.1\},\\
\tau_\rho&=\tau_{\rho,\min}+U(0,1)
(\tau_{\rho,\mathrm{hi}}-\tau_{\rho,\min}).
\end{aligned}
\]

QTDB/GSC/SHD：τα、τρ、两项 τη 分别在 log 区间均匀抽样，再取 exp，不能写成线性均匀分布。

五任务隐藏 W_in 为 Xavier uniform，W_rec 为 orthogonal（默认 gain=1）；隐藏偏置若存在则为 0。S/PS 线性输出也显式 Xavier uniform、偏置 0；QTDB/GSC 的线性输出保留 nn.Linear 构造默认，须锁定运行库版本。SHD 输出层采用同任务神经元初始化。QTDB 的 CLI 时间常数/频率参数未被放入传给模型的 neuron_config，改变这些 CLI 参数当前不会改变层默认区间；新版须保证配置确实进入模型。

### D2. 新版读出矩阵

五任务采用可追溯的原 scalar-reset 初始化分布：

\[
c_j\sim\mathcal N(0,\sigma_\kappa^2),\quad
g_{0,jk},g^{\rm init}_{1,jk}\sim\mathcal N(0,0.05^2),\quad
\bar g^{\rm init}_{1,jk}=c_jg^{\rm init}_{1,jk}.
\]

c 是**一次性初始化抽样**，不作为模型参数保存或训练；同一神经元的第二行三个条目共享同一个 c。随后只学习 g₀ 与 bar_g₁。对应第二行各条目的边际标准差为 S/PS/QTDB 0.0025、GSC 0.005、SHD 0.01；这些是分布计算值，不是测量结果。不能直接把第二行改为 N(0,0.05²)，也不能用独立高斯近似替换整个乘积分布而声称保留原初始化。

源程序未见针对 κ、G 或 u¹ 的单独参数正则。新版不添加单独正则，保留本表的优化器配置。该映射保持固定参数前向表示，不保证重新训练的轨迹或准确率相同。

### D3. 初态与复位梯度

**代码事实：**五任务 x 和 prev_spike 为零，但两项 u 每次初始化为 0.1×U[0,1)。训练和评价都会重新随机抽样；原代码并非全部零初态。SI-DMS 的内在状态为零。

**新实验规则：**为避免评价结果依赖重复抽取的随机初态，五任务和 SI-DMS 的 x、h、u⁰、prev_spike 统一设为零；每个独立样本/新 batch 重置，S/PS 的 chunk 之间只 detach、不清零。这是相对原五任务源码的明确改变，旧/新成绩差异不能全部归因于删除 λ。如果另做原 scalar-reset 到新版的公式等价检查，应使用 h_init=κu¹_init 的对应初态，而不是混用零初态。

五任务 surrogate 使用 lens=0.5、scale=6、height=0.15、gamma=0.5；阈值判断源码为 >0，SI-DMS 为 ≥0。新版统一采用膜候选 **严格大于 θ** 时发放，匹配五任务源程序；将等号边界写入实现规格。保留同一多高斯反向 surrogate。复位项和循环脉冲都保留 surrogate 梯度，不在单步中 detach；仅 S/PS chunk 边界截断计算图。源码没有证据支持“复位梯度已 detach”的表述。

### F2. 干预操作

- 在 delay 中为每个样本均匀无放回选 K 个时间步；每个选中时间步独立无放回选 n=max(1,round(64f)) 个神经元。f=0.15 时为 10 个，实际比例 10/64=15.625%；表中 15% 是名义值。round 沿用 Python 取整语义，不改成 floor。

- 当前 `intervention_margin» 虽在 YAML 中定义，cells 调用没有传入该字段，实际采用 _force 的默认 0.05；新版显式固定并传递相同值。
- 当前模型级自然发放率为“非干预位置的脉冲和 / 非干预位置数”，覆盖全序列、全 batch、所有隐藏单元。强制位置同时排除分子和分母，不只减掉强制脉冲数。
- SPRiF 的 x/h 正常更新，不受膜覆盖操作直接改写；MEMORY_RESET5 仍在真实发放后按其定义改写谱状态。
- 本实验联合改变膜候选、脉冲、复位和后续循环输入，结论针对完整模型响应。
