# SI-DMS 更新数据对比图

三张图按照约定分开排版：六模型热图、干预次数曲线、SPRiF 单次脉冲回放。均提供 PDF，PNG 仅用于预览。

## 热图和曲线

- 直接读取更新后的 Clean 和 Intervention 两份评估 JSON；各包含六个模型、五个随机种子。
- 保留零次干预及名义干预比例 15% 的条件。每个干预时刻对 64 个神经元中的 10 个施加干预，实际比例为 15.625%。
- 热图：每个模型、训练方式、延迟和干预次数下，显示五个种子的平均准确率。色卡沿用旧图的 YlGnBu，范围为 0.5–1.0。新数据所选条件均在此范围内。
- 曲线：先对每个种子的五个延迟等权求平均，再计算五种子的均值和样本标准差；阴影表示均值 ± 标准差。新数据的标准差约为 0.0008–0.0049，因此阴影比旧图窄，部分被曲线覆盖。
- 曲线、标记、模型颜色、图例顺序、背景和坐标样式沿用旧图。横轴干预次数作为离散条件等间距排列。

## 脉冲回放

- 回放使用现有的两个 SPRiF seed 0 检查点及之前重建的同一 A–A 输入；无干预和 K=8 的输入一致。
- 两种训练方式各展示 10 个神经元，同一训练方式下两种干预条件使用同一组神经元。不同训练方式选出的神经元不作逐个对应。
- 新版评估 JSON 与之前用于回放记录的评估文件哈希不同；现有检查点与回放文件的哈希一致，但仅凭更新后的 JSON 无法确认这些检查点与更新后的评估数值是否来自同一批运行。
