# 组合图代码验证记录

- 验证范围：输入接口、固定参数下的时间核、单试次轨迹回放、模型复位、组合版面及结果保护；不包含任何正式模型训练。
- `tests/test_composites.py` 使用临时合成数据和随机初始化的模型检查流程；临时数据不作为论文结果。核对时间核与独立的局部重放、零滞后和一步滞后的解析式一致，并检查两类轨迹和 smoke 数据拒绝逻辑。
- `tests/test_training_bundle.py` 检查两组训练任务只选择四个必需模型、已完成的 checkpoint 不重复训练、数据路径预检、`MEMORY_RESET5` 单步公式和参数量，以及两个绘图入口直接读取 checkpoint。测试仅使用临时初始化模型及模拟输入，没有执行优化器更新或训练。
- 本机没有 torchvision 和 librosa；未安装依赖，也未在本机执行真实数据训练或 MNIST 自动取样。目标服务器的依赖、数据与正式 checkpoint 仍需实际运行核验。
- 两个绘图脚本的静态检查没有 FAIL；保留旧版 8.4 英寸画布及 PNG 预览，检查提示最终投稿尺寸、栅格交付格式需要按期刊要求确认。
- 临时测试图均通过面板对齐和 PDF 最小字体检查。渲染碰撞检查没有 FAIL，但机制图有 4 处、时间核图有 1 处填充区域边缘 WARN；已检查测试图，属于相邻轴/填充区域边缘的检测提示。正式数据改变曲线和文字后必须重新检查，不可把临时测试通过当作正式成图验收。
- `_vendor/audit_figure_collisions.py` 和 `_vendor/audit_pdf_text.py` 可用于对正式 PDF 重新检查；前者需要环境中已有 PyMuPDF。
- PS-MNIST / SHD 回放从用户提供的 checkpoint 和测试样本重建网络，MEMORY_RESET5 复位规则由代码按稿件公式明确施加。checkpoint 是否确实来自相同规则、模型和随机种子必须由原始实验记录核实。
- 所附历史 ASRNN 时间常数与用户已有原始数据逐值一致，但旧数据的实验来源、种子及 ECG/QTDB 对应关系仍需核实。原来的 λ 分布和相关性面板不适用于新版，机制图只保留旧版版面，不保留这些面板的旧含义。
