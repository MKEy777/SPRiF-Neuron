## 1. 新主模型：SPRiF-SCALAR

状态为三维谱状态 x、辅助滤波状态 h 和膜坐标 u^0：

~~~text
I_t = W_in s_t + W_rec z_(t−1) + b
x_t^- = A x_(t−1)^+ + B I_t
A = diag(α, ρ R_ω)
B = [1−α, 1−ρ, 0]^T

h_t = η_1 h_(t−1) + bar_g_1^T x_t^-
u_tilde^0 = η_0 u_(t−1)^0 + h_(t−1) + g_0^T x_t^-
z_t = H(u_tilde^0 − θ)

u_t^0 = u_tilde^0 − z_t θ
x_t^+ = x_t^-
~~~

R_ω 为原二维旋转块；α、ρ、η 的约束与原稿一致。bar_G=[g_0^T; bar_g_1^T] 是直接学习的 2×3 矩阵。

- 状态：x 三维、h 一维、u^0 一维，共 **5 个**。
- 动力学学习参数：α、ρ、ω、η_0、η_1 五个，加 bar_G 的六个，共 **11 个**。θ 沿用任务原固定阈值；突触、偏置和输出参数另计。
- 不再单独学习 λ 或 κ，不用换符号方式保留独立复位方向或耦合系数。
- 膜候选使用 **h_(t−1)**，不能将其替换成刚计算的 h_t。
- 实现状态键为 `x`、`h`、标量 `u`；循环层另保存 `prev_spike`。独立序列零初始，H(0)=1，与当前正文一致；S/PS 截断边界保留数值状态并 detach。
- h 不受当前步直接复位，但继续滤波并驱动膜坐标。不能因 κ 被吸收而删除 h。
- 局部状态可组织为四维无直接复位的线性记忆/滤波状态 (x,h)，以及一维复位膜状态。三维谱块仍保留；h 不必比 x 更慢。
- 递归脉冲可能间接改变未来输入及记忆。局部线性稳定性不等于整个递归网络稳定性。

## 2. κ 的吸收与等价范围

原 G 的两行为 g_0^T、g_1^T。先令 λ=0，原第二坐标满足：

~~~text
u_t^1 = η_1 u_(t−1)^1 + g_1^T x_t^-
u_tilde^0 = η_0 u_(t−1)^0 + κ u_(t−1)^1 + g_0^T x_t^-
~~~

定义 h_t=κu_t^1、bar_g_1=κg_1，即得到第 1 节方程。没有除以 κ；κ=0 时，对应 h_init=0、bar_g_1=0，同样保持膜及脉冲输出。

等价条件与执行要求：

1. κ 是每神经元内不随时间步变化的系数，原 G 第二行自由学习；辅助状态不另有必须保留的固定幅度或独立输出约束。
2. 初态相应转换为 h_init=κu_init^1。若沿用原初始化，bar_g_1_init=κ_init g_1_init；零状态仍为零。
3. 在固定参数与对应初态下，λ=0 模型和此参数化的膜/脉冲序列等价。**原含 λ 的 Full 到 λ=0 是模型改变**，不能与这一步等价重参数化混为一谈。
4. 直接学习 bar_g_1 改变优化参数化；针对原 κ/g_1/u^1 的约束或正则需明确新处理方式。重新训练的准确率仍需测量。
5. 11 指此写法实际学习的动力学系数数量，不把参数计数本身作为新颖性证明。

## 3. 记忆复位控制：MEMORY_RESET5

保持第 1 节所有方程，在谱读出、辅助滤波、发放及膜复位之后，将 x 更新为：

~~~text
b_hat = B / ||B||_2
x_t^+ = x_t^- − γ z_t θ b_hat
γ = 1（固定，不学习）
~~~

下一步使用 x_t^+；当前步 h_t 使用复位前的 x_t^-，不额外直接复位 h。由于 α、ρ 在开区间 (0,1)，B 理论上非零；数值极小范数处理须在正式运行前确定并记录。

- 同样 **5 状态、11 动力学学习参数**、相同网络宽度；不重新加入 κ。
- 使用固定软复位直接改写三维谱记忆，避免把整个记忆清零作为唯一控制。
- 选择输入方向作为可复现控制，不声称代表所有记忆复位形式。
- 记录 ||Δx||、bar_G 与输入驱动尺度；γ=1 不自动保证与膜复位的功能强度相同。
- 若关键差异受尺度支配，补少量预先确定的 γ 诊断或限制机制结论；不能挑选最差 γ 展示。
- 本控制测试特定谱记忆复位路径，未直接复位全部四维 (x,h)，不单独证明全部鲁棒性来自该路径。

## 4. 实模态控制：REAL_MODES3

保持辅助状态、膜候选、发放与标量复位，替换三维谱记忆：

~~~text
A_real = diag(a_1, a_2, a_3)
B_real = [1−a_1, 1−a_2, 1−a_3]^T
a_i ∈ (0,1)，分别学习
x_t^- = A_real x_(t−1)^+ + B_real I_t
x_t^+ = x_t^-
~~~

- 三个实衰减参数替代 α、ρ、ω；加 η_0/η_1 和 bar_G 六个参数，总数仍为 **11**，状态仍为 **5**。
- a_1 的时间常数沿用 α 区间，a_2/a_3 分别独立采样原 ρ 区间；bar_G 与其余状态采用新主模型方案。
- 检查 [B, AB, A²B] 的奇异值与数值秩，事先记录容差；重复极点或近退化不能被当作三个有效可驱动模态。
- 报告 B 与 bar_G 尺度；结论限定为所测实/复模态组织差异，不声称只改变一个 ω 标量。
- 不用原 ω=0 时第三坐标失去输入的退化控制替代本控制。
